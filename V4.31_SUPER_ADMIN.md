# FamilyHero 4.31.1-beta

## Kullanım

1. Mevcut `admin` hesabıyla giriş yapın.
2. Sol menüden **Platform → Aile Yönetimi** seçin.
3. Aile adı girin; aile kodu ve yönetici kullanıcı adı otomatik önerilir.
4. Geçici şifreyi belirleyip aileyi oluşturun.
5. Listeden **Aileye geç** ile o ailenin admin panelini açın.

> `admin` kullanıcı adı platform genelinde zaten kullanıldığı için yeni ailelerde `ailekodu_admin` biçimi önerilir.
