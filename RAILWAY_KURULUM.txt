FAMILYHERO 4.1 - RAILWAY KURULUMU

1. FamilyHero servisinde Variables bölümünde şu değişken bulunmalı:
DATABASE_URL=${{Postgres.DATABASE_URL}}

2. E-posta ile şifre sıfırlama için ayrıca ekleyin:
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=<gmail adresiniz>
SMTP_PASSWORD=<Google uygulama şifreniz>
SMTP_FROM=<gmail adresiniz>
FAMILYHERO_SECRET_KEY=<uzun rastgele bir anahtar>

3. Dosyaları mevcut proje klasörünün üzerine kopyalayın, ardından:
git add .
git commit -m "PostgreSQL profil ve not sistemi"
git push origin main

4. Railway Deploy Logs içinde şu satırı arayın:
FamilyHero PostgreSQL veritabanı hazır; DATABASE_URL kullanılıyor.

5. Test: görev girin, çıkış yapın, tekrar girin; kayıt korunmalıdır.
